三、技术栈：为什么撮合引擎必须用 C++/Go？

关键数字：单节点 10,000+ TPS，微秒级清算。

Java/Go 写的撮合引擎在万级并发下会出现 GC 停顿，导致用户下单卡单、行情延迟。正经交易所的撮合层一定是 C++ 内存级架构，订单簿在内存里维护，MySQL 只做持久化，Redis Cluster 做分布式缓存。

如果你拿到的"交易所源码"是 PHP 或纯 Node.js 写的撮合层，基本可以判定是玩具——并发上去必崩。
